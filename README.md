# Lung X-Ray AI

**AI-assisted chest X-ray screening system designed to prioritize potentially abnormal scans for review.**

### 🚀 Live Demo

**[View Live Application](https://lung-disease-detection-vercel.vercel.app/)** · **[GitHub](https://github.com/Dhruv2604/Lung-Disease-Detection)**

## What It Does

Lung X-Ray AI applies computer vision and deep learning concepts to chest X-ray analysis, providing an AI-assisted workflow for identifying potentially abnormal scans and prioritizing them for further review.

### Key Features

* Chest X-ray image analysis
* Batch image processing
* AI-assisted classification
* Confidence scoring
* Abnormal-case prioritization
* Scan-level result tracking
* Human-in-the-loop verification
* Interactive web application

### AI Pipeline

```text
Chest X-Ray
     ↓
Image Preprocessing
     ↓
CNN-Based Analysis
     ↓
Classification
     ↓
Confidence Score
     ↓
Normal / Abnormal
     ↓
Priority Review
```

### Tech Stack

**Python · CNN · Computer Vision · NumPy · Pandas · JavaScript · HTML/CSS · Vercel**

### Why It Matters

Demonstrates a **human-in-the-loop AI workflow** where machine learning assists high-volume image screening while keeping final decisions with domain experts.

## Future Scope

Transfer learning, Grad-CAM explainability, larger clinical datasets, DICOM support, model calibration, and clinical validation.
